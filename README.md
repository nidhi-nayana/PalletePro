# PalettePro

<div align="center">
  A powerful and intuitive color palette generation tool for designers and developers.
</div>

## 🎨 About The Project

PalettePro is a modern color palette generator that helps designers and developers create beautiful, harmonious color schemes for their projects. Whether you're working on a website, mobile app, or graphic design project, PalettePro makes it easy to find the perfect color combinations.

## ✨ Features

- 🎯 Generate harmonious color palettes with a single click
- 🔍 Extract color palettes from images
- 💾 Save and organize your favorite palettes
- 🔄 Export palettes in various formats (HEX, RGB, HSL)
- 🌈 Color blindness simulation
- 📱 Responsive design for mobile and desktop

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/nidhi-nayana/PalettePro.git
```

2. Install dependencies
```bash
cd PalettePro
npm install
```

3. Start the development server
```bash
npm start
```

## 🔧 Usage

1. Visit the application in your browser
2. Choose a generation method:
   - Random palette generation
   - Start with a base color
3. Customize your palette
4. Export in your preferred format
